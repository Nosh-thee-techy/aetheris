Nothing on this page moves real money. The escrow holds Sepolia test ETH. The M-PESA step below is a labelled sandbox record and calls no payment service.

01

The escrow

A contract holds testnet ETH and pays only a finalized claim, once, to a table fixed before any claim existed. The funder cannot take money back during the season, and can reclaim only what was never credited after it ends.

Who gets paid, and when

This table is the committed policy, read from the escrow. It was locked before the pool was funded, so it cannot change.

The beneficiaries in this deployment are placeholders. Each is an address derived from a hash, and nobody holds a key for it. A release would credit them correctly, and the ETH would then sit there. A real deployment commits real recipients, such as an insurer’s payout account or an aggregator’s wallet.

Withdraw

Money never gets pushed to anyone. Returned bonds, returned stakes, slashed bonds and payouts all wait as a balance that the owner pulls. Connect a wallet to see yours.

04

The M-PESA sandbox mirror

When the escrow emits a release, watcher/mirror.py turns it into a record that a Daraja sandbox client could read. Today that is all it does.

Sandbox

What exists

A function that copies one finalized release into a record. Every record is labelled SANDBOX and says no money moved.

It does not call Safaricom, hold credentials, or send shillings. It is not running as a service, so no record has been written for this deployment.

The shape of a record

{
  "label": "SANDBOX",
  "rail": "daraja-sandbox",
  "moved_kes": false,
  "trigger_id": "<claim id>",
  "zone": "<place>",
  "amount_wei": <wei released>
}

This is the format, not a payout. No example amount is shown, because none has been released.
