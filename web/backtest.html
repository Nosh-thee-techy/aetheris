Backtest · one season · counts only

Where the sources agreed, disagreed, and what was missed

One flood week, 7 places, one frozen rule. We report counts, not an accuracy percentage, because seven news reports cannot carry one. The rule was fixed on 2026-10-12, before this week was scored, and we did not tune it afterwards.

Rainfall was “yes” in every place, so it told us almost nothing about which places flooded. It disagreed with radar in 3 of the 4 places radar could judge.

Requiring radar means 6 of 7 reported floods produced no claim: 3 where radar saw too little open water, and 3 where it could not look. Rainfall alone would have found all 7, but there is no “did not flood” place in this log, so we cannot say how often rainfall alone would raise a false alarm. Neither number is an accuracy figure. 02

Check that the rule on the chain is the rule in the repository

Each claim id contains a hash of config/rule.yaml. This button hashes the file here, in your browser, then asks the contract what hash it holds. If someone had changed the rule after the fact, they would not match.

The file is stored byte for byte, line endings included, because the hash covers every byte. See .gitattributes.

04

Reproduce it

From a clone of the repository, with Python 3:

python -m backtest.score          # reads labels/label_log.csv and backtest/observations.csv
                                  # writes backtest/results/counts.csv
python -m unittest backtest.test_score backtest.pipeline.test_pipeline watcher.test_mirror
python web/build.py               # rebuilds these pages from the same files

The radar fractions come from backtest/checks/radar_fraction.py, which needs network access to Microsoft Planetary Computer. The scored result does not depend on rerunning it: the measured values are in the CSV above.

05

What this cannot tell you

  • No “did not flood” labels.Without them there are no false alarms to count, so no precision, and we publish none.
  • Seven reports favour reachable places.Places that reporters and rescuers could reach are over-represented. Unknown is not “no flood”.
  • Boxes are not flood outlines.A ward box mixes dry and wet land, which pulls the radar fraction down. That is one reason radar says no in 3 places.
  • One week.Nothing here says how the rule behaves in another season. It is a frozen first rule, to be judged on a season it has not seen.
