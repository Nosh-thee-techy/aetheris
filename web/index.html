02

What we have built

A check you can open, not a score you are asked to trust.

Decorative picture. Not the 6 May 2024 Sentinel-1 scene, and not a measured flood outline.

Two sources, one frozen rule

Radar is mandatory. Rainfall corroborates. The rule in config/rule.yaml was frozen before this week was scored. Its hash is on the contract. If the bytes change, the hash will not match.

A claim you can challenge

When both sources sign, a 24-hour window opens on Sepolia. Anyone with a wallet can challenge. One named referee key can uphold or reject. Payouts are testnet ETH in an escrow, once, after Finalized. M-PESA in this project is a labelled sandbox.

A desk for each job

The insurer sees rainfall-only versus this rule. The reinsurer sees one named event layered like a catastrophe model, with an indicative JRC depth-damage sheet labelled adapted or assumption. Responders get a second-signal board. ICPAC and Kenya Met get a connected source desk from the same files. Research gets the counts and the commands. Farmers get one sentence. None of this is machine learning.

04

What this is not

Say the limits in the same breath as the work.

  • Not machine learning.A frozen prior on open water and a catchment rainfall line. We did not train on this week.
  • Not an accuracy percentage.Seven news reports cannot carry one. We publish counts.
  • Not a catastrophe model.The reinsurer page is one named flood. No AAL, EP curve, or return period.
  • Pictures are not evidence.The photographs are decorative. They are not the 6 May Sentinel-1 scene and not a flood outline.
  • Unknown is not “no flood”.Three places have no outline we would measure. Radar was not run there.
  • Payouts are not real.Testnet ETH. M-PESA is a sandbox. The contracts are unaudited.
